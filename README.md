# GTA VI — GT Landing Page

Proyecto académico para **Procesos y Soluciones Tecnológicas, S.A.**
Landing page estática que emula la presentación del videojuego GTA VI.

## Tecnologías usadas

- HTML5 semántico
- CSS3 puro (sin frameworks)
- JavaScript Vanilla (sin librerías)
- normalize.css v8.0.1

## Estructura del proyecto

```
gta-vi-gt/
├── index.html
├── assets/
│   ├── css/
│   │   ├── normalize.css   ← Reset de navegadores
│   │   ├── style.css       ← Estilos principales
│   │   ├── navbar.css      ← Widget: barra de navegación
│   │   ├── hero.css        ← Widget: sección principal
│   │   ├── buttons.css     ← Widget: botones
│   │   └── sections.css    ← Widget: secciones y footer
│   └── javascript/
│       └── main.js         ← JavaScript Vanilla
├── design/                 ← Mockups y guías de diseño
├── fonts/                  ← Fuentes locales (si aplica)
└── images/                 ← Imágenes del proyecto
```

## Restricciones técnicas cumplidas

- ✅ Solo CSS3 (sin Sass, sin ITCSS)
- ✅ Sin Bootstrap, Foundation ni otros frameworks CSS
- ✅ Sin Angular, Vue ni React — JavaScript Vanilla
- ✅ Sin PHP ni lenguajes de servidor
- ✅ Sin MVC ni programación por capas
